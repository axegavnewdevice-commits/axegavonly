# Axegavonly — Arabic Scrabble PWA

Responsive Arabic Scrabble web app prepared as a Progressive Web App (PWA) for Vercel.

## Deploy

This is a static site. Import the repository into Vercel with no build command and no output directory. The `index.html` file is at the repository root.

## Install

- **Android / desktop Chromium:** open the HTTPS site, then use the app's install button or the browser menu's **Install app** option.
- **iPhone / iPad:** open the site in Safari, tap **Share**, then **Add to Home Screen**.

The service worker caches the app shell and public static dependencies after they have been visited online. Firebase services and other network-backed features still require an internet connection.
